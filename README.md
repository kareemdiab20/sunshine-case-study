# Sunshine PS

Modern fashion e-commerce platform for Android, iOS and Web.

> ⚠️ This repository is a project showcase only.
> Source code is private.

## Overview

Sunshine PS is a complete fashion e-commerce platform designed for a premium shopping experience across mobile and web.

The project includes:

- Customer mobile application
- Web application
- Admin dashboard
- Firebase backend
- Product & inventory management
- Orders management
- Authentication
- Shopping cart
- Checkout
- Push notifications
- Responsive UI
- Multi-platform deployment

## Tech Stack

- React Native
- Expo
- React
- TypeScript
- Firebase
- Firestore
- Firebase Authentication
- Firebase Storage
- Cloud Functions
- REST APIs

## Platforms

- Android
- iOS
- Web
